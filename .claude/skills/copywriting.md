# Copywriting Skill

## When to use

Read this skill before any task involving:
- Microcopy (button labels, empty states, error messages)
- Window titles and app names
- Project case study headlines or summaries
- Bio / About copy
- SEO meta titles and descriptions
- Social share text (OG titles)
- Blog post titles
- Easter egg copy (when defined)

## Working principles (until voice is locked)

- **Use Nic's own voice.** Any user-supplied copy is authoritative — don't rewrite.
- **Avoid AI-generated tells:**
  - No "delve," "navigate the landscape," "in today's fast-paced world"
  - No em-dash overuse
  - No three-part rhythm ("clear, concise, and compelling") as a default
  - No vague superlatives ("amazing," "incredible," "groundbreaking")
- **Be specific.** "Built for ESPN" beats "worked with major brands."
- **Active voice.** "I designed this" beats "this was designed by me."
- **Sentences can be short.** Fragments are fine when they earn it.

When `copywriting.md` is finalised, this section will define:

### App / window names
- The names of each desktop icon and how they're titled in their open window
- Whether titles are sentence case, Title Case, or lowercase

### Button labels
- Standard pattern for primary CTAs

- What the Playground says when a card is loading

### Error states
- What happens if Rive fails to load (silent fallback or visible message)
- What 404 says

- OG title vs page title rules
