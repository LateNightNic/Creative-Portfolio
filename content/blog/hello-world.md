## Why a blog

This is the first real post published from the new Markdown-driven pipeline. Every post here lives as a plain `.md` file in `content/blog/`, gets rendered into a real static HTML page at build time, and shows up in the Blog window on the desktop.

Text, images, and embedded video all work the same way — write Markdown, it becomes a page.

## A placeholder image

Images are referenced with a root-relative path (starting with `/`), since a post's generated page can live at any folder depth under `/blog/[slug]/`.
